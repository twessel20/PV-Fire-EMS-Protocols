PVFIRE Protocol Administration

Officer / administrator maintenance
Officer/Admin only: publishing access is controlled by GitHub repository write permission. Firefighters using the protocol site do not receive these controls.

Replace one protocol

Upload the approved replacement protocol PDF. The filename can be anything.

The indexer reads the PDF, attempts to identify the matching official protocol by title, replaces only that protocol, rebuilds its searchable content, and preserves the uploaded PDF as the new source document.

If the system cannot confidently identify the protocol, it publishes nothing.

After processing, verify the live mobile entry against the approved source PDF before treating the update as complete.

Replace the complete protocol book

Use this for a complete department-wide protocol revision. Upload the approved manual as protocol-book.pdf.

The indexer rebuilds the searchable protocol set. If it cannot confidently locate all expected protocols, it stops rather than publishing a partial full-book update.

Clinical review
