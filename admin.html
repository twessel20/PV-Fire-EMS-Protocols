Officer / administrator maintenance
Access control: publishing is enforced by GitHub repository write permission. Only designated officers/administrators should be granted write access.

Replace one protocol

1. Name the approved replacement PDF exactly with the existing protocol ID, for example adult-chest-pain-stemi.pdf.

2. Upload it to updates/single/.

3. The automated indexer replaces only that protocol and refreshes its search content.

4. Review the live entry against the uploaded source PDF after the workflow finishes.

Replace the complete protocol book

Upload the approved book as protocol-book.pdf to updates/full/. The workflow attempts to rebuild the existing index and stops if protocol titles cannot be confidently located.

Important

Do not publish draft clinical material. PDF extraction is a convenience for indexing; the approved source PDF remains authoritative.
